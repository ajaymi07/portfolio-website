# Personal Portfolio Website

A clean, modern, and responsive portfolio built with HTML, CSS, and JavaScript.

## 🚀 Live Demo
* **Website:** [https://ajaymi07.github.io/portfolio-website/](https://ajaymi07.github.io/portfolio-website/)
* **Repository:** [https://github.com/ajaymi07/portfolio-website](https://github.com/ajaymi07/portfolio-website)

---

## 🌟 Key Features
* **Responsive Layout:** Works smoothly on mobile, tablet, and desktop.
* **Dark / Light Mode:** Theme toggle with saved user preference.
* **Mobile Menu:** Interactive hamburger navigation.
* **Form Validation:** Client-side JS validation for the contact form.
* **Animations:** Scroll reveal effects using `IntersectionObserver`.
* **Downloadable Resume:** Direct PDF download link.

---

## 🛠️ Built With
* **HTML5** | **CSS3** | **JavaScript** | **Font Awesome Icons**
